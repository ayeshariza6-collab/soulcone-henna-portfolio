# Soulcone – Premium Henna & Mehendi

Soulcone is a modern and elegant website created for a premium henna and mehendi brand. The website provides visitors with information about services, products, gallery, reviews, FAQs, and booking options.

## 🌿 Live Website

https://soulcone-henna.lovable.app

## ✨ Features

- Modern responsive design
- Premium henna and mehendi service showcase
- Bridal and custom mehendi services
- Product section
- Image gallery
- Customer reviews
- Frequently Asked Questions
- Booking and enquiry options
- Contact information
- Instagram and WhatsApp integration
- Mobile-friendly layout

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- JavaScript
- HTML
- CSS

## 📌 Project Purpose

This project was created to build a professional online presence for Soulcone and provide customers with an easy way to explore services, view designs, and make enquiries or bookings.
